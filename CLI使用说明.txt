================================================================================
  面部去高光 - 命令行使用说明
================================================================================

【核心命令，记住这一条就够了】

  run_facehi_terminal.bat -i "图片或文件夹路径"

  示例（先试这条）：
  run_facehi_terminal.bat -i "data\1.png"

  处理完成后，结果会保存在【输入图片同级目录】，文件名加 _output。
  例如输入 data\1.png，输出就是 data\1_output.png


--------------------------------------------------------------------------------
【参数说明】
--------------------------------------------------------------------------------

  -i  或  --input     【必填】要处理的图片，或装有多张图片的文件夹
  -o  或  --output     【可选】输出位置；不填则自动保存在输入图片旁边
  --mode               【可选】处理模式；不填默认「常用模式」

  只有 -i 是必填，其他都可以不写。


--------------------------------------------------------------------------------
【-i 怎么填】
--------------------------------------------------------------------------------

  可以写：
    单张图片    data\1.png
    整个文件夹  data
    绝对路径    D:\我的照片\face.jpg
    正斜杠      D:/我的照片/face.jpg

  路径有空格或中文时，请用英文双引号包起来。


--------------------------------------------------------------------------------
【-o 怎么填（可选）】
--------------------------------------------------------------------------------

  不写 -o：
    每张结果保存在【输入图片同级目录】，如 photo.jpg -> photo_output.jpg

  写具体文件：
    -o "D:\结果\out.jpg"     保存到这个文件

  写文件夹：
    -o "D:\结果\"            批量时所有结果保存到这个文件夹


--------------------------------------------------------------------------------
【--mode 怎么填（可选）】
--------------------------------------------------------------------------------

  常用模式       默认，速度和效果比较均衡（推荐）
  高保真模式     更保守，改动更小
  最高质量模式   最慢，质量最高

  示例：
  run_facehi_terminal.bat -i "data\1.png" --mode 高保真模式


--------------------------------------------------------------------------------
【常用例子】
--------------------------------------------------------------------------------

  1. 最简单（只写 -i）
     run_facehi_terminal.bat -i "data\1.png"

  2. 处理整个文件夹
     run_facehi_terminal.bat -i "data"

  3. 指定输出文件夹
     run_facehi_terminal.bat -i "data" -o "D:\输出\"

  4. 指定输出文件
     run_facehi_terminal.bat -i "data\1.png" -o "D:\输出\result.png"


--------------------------------------------------------------------------------
【怎么打开命令行】
--------------------------------------------------------------------------------

  方法1：安装目录里双击 run_facehi_terminal.bat（会打开终端并显示示例命令）
  方法2：桌面版软件里点「命令行模式」按钮，可复制命令、打开说明书、打开终端

  安装目录默认在：
  C:\Users\你的用户名\AppData\Local\FaceHighlight Simple\


--------------------------------------------------------------------------------
【常见提示】
--------------------------------------------------------------------------------

  1. W0000 / INFO 开头的一串英文
     这是模型加载时的正常提示，不是报错，可以忽略。

  2. 提示「输入文件不存在」
     多半是文件名或后缀写错了。比如 data 里没有 1.jpg，但有 1.png，
     请改成：run_facehi_terminal.bat -i "data\1.png"

  3. 必须在安装目录里运行 run_facehi_terminal.bat
     不要在源码开发文件夹里直接运行。

  4. 支持格式：jpg、jpeg、png、bmp、webp


================================================================================
  附录：整个去高光流程（了解即可）
================================================================================

  单张 1080P 图片在 CPU 上大约需要 10 秒左右，主要分五步：

  第一步  人脸定位
          用 MediaPipe 检测人脸关键点；失败时用 OpenCV LBF 兜底。
          目的是找到眼睛、眉毛、鼻子、嘴巴、额头、脸颊、下巴和轮廓。

  第二步  划分区域
          把额头、鼻梁、鼻尖、左右脸颊、下巴标为「高光候选区」；
          把眼睛、眉毛、嘴唇、牙齿标为「保护区」，避免误改。

  第三步  高光检测
          参考双色反射模型：皮肤 = 真实肤色漫反射 + 表面油光镜面反射。
          不是简单找白像素，而是结合 RGB 亮度、HSV、Lab 亮度、
          局部异常和区域自适应基线，判断哪里反光过强。

  第四步  去高光处理
          只在高光区域内做：亮度压制、色度恢复、纹理保留、局部融合。
          把过亮区域拉回周围正常肤色，尽量保留皮肤纹理，避免磨皮感。

  第五步  真实性检查
          检查修改面积是否过大、眼睛嘴唇是否被误改、背景衣服是否受影响。

  整体目标：只去掉证件照额头、鼻子、脸颊、下巴的反光，
  让照片像在更均匀光照下拍的，同时尽量不改变五官和脸型。
